## 一、这个算法在做什么

**变分推断**要解决的核心问题是：后验 `p(Z, π, μ | X)` 通常**无法解析计算**。
均值场 VI 的做法是——把后验**强行拆成独立因子**（平均场近似），然后用坐标上升让一个可计算的下界最大化：

```
真实后验  p(π, Z, μ | X)          ✗ 不可解
均值场     q(π, Z, μ) = q(π) · q(Z) · ∏_k q(μ_k)   ✓ 全闭式
目标       max_q  ELBO(q)  =  E_q[ln p(X,Z,π,μ)] − E_q[ln q]
```

**每一步坐标上升都保证 ELBO 不减**（CAVI 定理），这就是本项目的头号不变量。

### 模型（Bishop PRML §10.2）

| 层 | 分布 |
|---|---|
| 混合权重 | `π ~ Dirichlet(α₀·1_K)` |
| 簇均值 | `μ_k ~ N(μ₀, σ₀²I)` |
| 观测 | `x_n \| z_n ~ N(μ_{z_n}, σ²I)`（σ² 已知） |

### CAVI 的三步闭式更新

```
① q*(μ_kd) = N(m_kd, s²_kd)
    1/s²_kd = 1/σ₀² + (Σ_n r_nk)/σ²
    m_kd    = s²_kd · ( μ₀d/σ₀² + (Σ_n r_nk · x_nd)/σ² )

② q*(π) = Dirichlet(α),   α_k = α₀ + Σ_n r_nk

③ q*(z_n) = Categorical(r_n),  ln ρ_nk = E[ln π_k] + E[ln N(x_n | μ_k, σ²)]
    E[ln π_k]        = ψ(α_k) − ψ(Σ_j α_j)          ← digamma
    E[ln N(x|μ,σ²)] = −(D/2)ln(2πσ²) − (‖x−m_k‖² + Σ_d s²_kd)/(2σ²)
```

ELBO 的 7 项全部写成闭式（含 Dirichlet 熵、Gaussian 熵、`lgamma`、`digamma`）——
没有采样、没有蒙特卡洛、没有数值积分。

### C. 精确 log 证据交叉验证 —— 本项目最硬的两条

```
K = 1（均值场精确，必须取等）：
    精确 log p(X) = -29.619215294301
    变分 ELBO     = -29.619215294300
    |Δ| = 3.6e-15                        ← 15 位有效数字取等

K = 2, N = 6, D = 1（穷举全部 2⁶ = 64 种分配）：
    精确 log p(X) = -10.746900385
    变分 ELBO     = -11.440047571
    间隙          = +0.693147186
    ln 2          = +0.693147181        ← 吻合到 5e-9
```

**第二条是教科书级的漂亮结果**：这个对称问题里，证据包含 **2 个标签互换的并列模式**
（`z=111000` 与 `z=000111`，两者密度完全相同），而均值场只能"看见"其中一个模式。
于是下界间隙恰好等于 `ln 2` —— **均值场对称破缺代价的精确值**，而不是一个模糊的"< 1 nat"。
（这也是 mean-field 著名的 mode-seeking 偏差：**它会低估证据，且往往不是低一点点。**）

## 四、UI 面板（`index.html`）

单文件、内联 CSS/JS、零外部依赖：

- **ELBO 收敛曲线** —— 单调不减，迭代全程可视化
- **后验聚类散点图** —— `q(μ_k)` 均值 (实心点) ± σ (虚线框) vs 真生成中心 (空心圈)
- **责任度热图** —— `K 行 × N 列`，色深 = `r_nk`
- **9 项实时自检** —— 每次点击「运行推断」实时重跑全部数学不变量
- **两种数据模式**：
  - **分离**（σ=0.70）→ 硬责任度（max 非归属 r ≈ 1e-7），3 步收敛，恢复率 100%
  - **重叠**（σ=1.30）→ **软责任度**（r 高到 0.435），29 步收敛，能看清 ELBO 曲线爬升

可调：`seed` / `K` / `N` / 重启动次数 / 数据模式。

## 六、设计上的两点判断

1. **自检只放数学不变量，不放"准确率"。** 准确率依赖数据难度（分离 100% / 重叠 87%），
   把它写成断言会让"检查通过"变成好消息而不是事实。所以准确率进统计卡，不变量进自检表。
2. **多次重启取最大 ELBO。** mean-field 是非凸的，会陷局部最优；但 ELBO 本身是**可比的目标函数**，
   所以"取最大"是有原理的，不是撒网。附带收益：8/8 seed 稳定 100%。
